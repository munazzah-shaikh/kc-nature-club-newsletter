**https://munazzah-shaikh.github.io/kc-nature-club-newsletter/**

## Enable GitHub Pages (one-time)

1. Open **https://github.com/munazzah-shaikh/kc-nature-club-newsletter/settings/pages**
2. Under **Build and deployment → Source**, choose **Deploy from a branch**
3. Branch: **main** · Folder: **/ (root)**
4. Click **Save**
5. Wait 1–2 minutes, then open the live URL above

## Upload the latest files

If the site is incomplete, upload these from the project zip to the repo root (GitHub → **Add file → Upload files**):

- `c0.js` … `c5.js` (newsletter content chunks)
- `kc_college_logo.b64` and `nature_club_logo.b64` (logos)
- Photos already in the repo: `thane_creek_group.jpg`, `poster_competition_girl.jpg`, `big_cat_gazette.jpg`

`index.html` is already configured to assemble everything.
